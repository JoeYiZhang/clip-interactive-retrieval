```mermaid
flowchart LR
    UI[交互界面 / API 调用方] --> API[HTTP API 适配层\n待实现]
    API --> S[InteractiveSession\n已实现]
```

边界说明：状态机不保存密码、用户身份或原始图片；`session_id` 必须由上层去标识化。文本反馈在进入核心前编码为向量，核心的幂等摘要只记录向量哈希，不写入原始文本。

## 3 单轮状态流

```mermaid
flowchart TD
    A[创建会话 round=0] --> B[retrieve Top-K]
    B --> C[记录实际曝光 ID]
    C --> D[提交 event_id 与显式反馈]
    D --> E{重复 event_id?}
    E -->|同内容| F[返回原 transition\n不重复加轮次]
    E -->|不同内容| X[拒绝冲突请求]
    E -->|新事件| G{反馈 ID 是否来自本轮曝光?}
    G -->|否| X
    G -->|是| H[更新累计正负集合]
    H --> I[计算候选查询与 cosine drift]
    I --> J{超过漂移阈值?}
    J -->|是| K[保留上一查询]
    J -->|否| L[采用候选查询]
    K --> M[round + 1]
    L --> M
    M --> N{达到 max_rounds?}
    N -->|是| O[completed]
    N -->|否| B
```

## 4 已实现的契约

| 契约 | 行为 |
|---|---|
| 编码器/索引版本 | 创建会话时不一致即拒绝 |
| 参考图过滤 | 每轮 Top-K 不返回初始参考图 |
| 曝光一致性 | accepted/rejected 必须来自最近一次真实曝光 |
| 显式负反馈 | 未点击不自动当作负样本 |
| 冲突反馈 | 同一事件同时接受和拒绝同一图片时拒绝 |
| 标签反转 | 后一轮显式接受会移除旧负标签，显式拒绝会移除旧正标签 |
| 事件幂等 | 相同 `event_id` 和相同内容只处理一次；不同内容复用 ID 时拒绝 |
| 漂移保护 | 超过阈值时保留上一查询，但事件仍计入轮次并留下原因 |
| 最大轮次 | 达到 `max_rounds` 后进入 `completed`，拒绝新反馈 |
| 快照 | 不暴露查询向量，只返回版本、轮次、标签和状态 |
