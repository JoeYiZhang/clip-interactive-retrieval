## 交接规则

- 接手人先运行 README 的三条验证命令。
- 任何真实实验先登记，再运行，再补结果路径。
- 未通过 `docs/02_需求与验收规格.md` 的退出门槛不得标记阶段完成。
- 合成烟雾测试不得作为论文或申请书中的科研指标。
- CIRR 原图未获官方/NLVR2 授权前不得从第三方镜像绕过申请。
- 不完整 FashionIQ 图库不得报告官方 Recall。
