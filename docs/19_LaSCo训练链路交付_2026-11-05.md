# LaSCo 训练清单与多正例训练链路

日期：2026-11-05。延续模型优先路线，本轮完成可在完整图片到位前执行的训练接入工作。

## 实际交付结果

| 项目 | 结果 |
|---|---|
| 训练清单 | 359,167 条有效记录，逐条保留来源行号、源 qid、图像 ID/路径和修改文字 |
| 验证清单 | 30,031 条有效记录，独立生成，不进入本轮梯度验证 |
| 样本键 | `lasco:split:原始行号`，隔离异常样本后仍保持来源位置稳定 |
| 空文字隔离 | train 101 条、val 6 条，原始标注不改写 |
| 多目标查询条件 | train 1,121 种、val 6 种具有多个已知目标；条件为同一参考图及仅统一空白后的同一修改文字 |
| 输入校验 | 官方划分文件夹、图片 ID 与文件名一致，拒绝越界路径及同 ID 冲突路径 |
| 正负样本处理 | 去重候选图片；排除参考图；同一查询的已知正确目标全部按正例处理 |
| 真实 GPU 训练一步 | 固定前 8 条有效 train 查询、14 张官方训练图片；CLIP 冻结，融合网络更新成功，损失有限，实测约 0.975508 |
| 全仓测试 | 41 passed，5.25 秒 |

共享参考图片而文字不同，不据此合并正例；语义相近但文字不同的情况也未自动推断。正例关系仅从相同查询条件的已知标注中提取，不宣称覆盖所有有效目标。训练与验证的正例关系表分别建立，图片 ID 交集再次检查为零。

本轮真实训练一步只验证损失、梯度和参数更新，不保存为正式候选模型，不构成性能提升证据。未使用 FashionIQ holdout、FashionIQ 官方 val 或 CIRCO 标签选择新参数。

## 代码与产物

| 路径 | 用途 |
|---|---|
| `src/cir_baseline/lasco_training.py` | 清单构建、查询条件正例表、候选屏蔽 |
| `src/cir_baseline/learned_fusion.py` 中的 `masked_multi_positive_loss` | 显式正例与候选有效性掩码的对比损失 |
| `scripts/prepare_lasco_training.py` | 全量清单生成与可选真实 train 图片梯度检查 |
| `tests/test_lasco_training.py` | 重复 qid 下的行身份、正例条件、参考图零梯度、路径/划分错配检查 |
| `artifacts/metrics/lasco_training_preparation.json` | 原始标注哈希、清单哈希、隔离记录、训练一步结果 |
| `artifacts/metrics/lasco_training_contract_tests.xml` | 全量 41 项回归测试证据 |
| `artifacts/training-data/lasco-v1/train.jsonl.gz`、`val.jsonl.gz` | 本地完整训练与验证清单，不随 Git 同步 |

清单压缩文件包含生成时间元数据，重复运行可能改变压缩文件 SHA256；样本键与逻辑记录按原始顺序稳定。每次生成后的实际文件哈希写入对应 summary，异机可按官方标注重新生成。

## 下一步交付门槛

1. 图片继续下载。训练侧图片需通过解码与版本校验，随后按本轮清单生成冻结 CLIP 向量缓存。
2. 固定小规模训练协议、训练子集和三个随机种子，比较原批内单目标损失与已知多正例损失；提前登记 dev 选择规则。
3. 依据足量 train/dev 结果决定是否扩大训练。小样本训练一步的损失不可代替检索 Recall。
4. 模型方案冻结后，完整官方图库上评测 CIRCO mAP，保留逐查询结果和复跑证据。

完整图片当前仍未验收，下载期间电脑需联网并避免休眠。无需用户整理清单或提供额外模型权重。
