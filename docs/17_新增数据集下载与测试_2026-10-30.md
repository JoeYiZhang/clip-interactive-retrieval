目前代理吞吐较低，GitHub 直接连接还遇到客户端证书信任问题。已使用系统证书库校验 HTTPS，未关闭证书验证；COCO 改为官方 S3 直连，多线程并支持续传。实测仍较慢，无法给出可靠完成时间。请以日志中的实际块进度为准。

## 自动验收与交接入口

| 文件 | 用途 |
|---|---|
| `scripts/download_coco_archives.py` | HTTP Range 与响应范围校验、续传清单、远端 ETag 检查、所有 ZIP 成员 CRC 校验、安全解压与 SHA256 |
| `scripts/fetch_lasco_annotations.py` | 获取完整原始标注，JSON 校验后落盘；来源和哈希写入 `D:\image_data\downloads\lasco_sources.json` |
| `scripts/test_additional_datasets.py` | 标注审查、隔离空文字、真实图片下载校验与两个模型的工程检索测试 |
| `scripts/validate_additional_data.py` | 整包校验凭证、所有标注引用图片存在性和最终 readiness 检查 |
| `scripts/finish_additional_download.py` | 重试训练标注获取，等后台图片下载结束后自动执行最终覆盖检查；未通过则保留未完成状态 |
| `artifacts/metrics/circo_download_smoke.json` | CIRCO 标注哈希、测试输入、实际候选排名 |
| `artifacts/metrics/lasco_download_smoke.json` | LaSCo 标注哈希、6 条隔离记录及实际候选排名 |
| `artifacts/metrics/additional_data_coverage.json` | 整库就绪门槛；当前 `pending_download`，不得当成完整验收通过 |
| `artifacts/metrics/additional_dataset_tests.xml` | 全部 36 项测试记录 |
| `artifacts/metrics/coco_download.log`、`coco_download_error.log` | 完整图片下载进度和错误（本机实时日志，不进 Git） |
| `artifacts/metrics/lasco_annotations_download.log`、`lasco_annotations_error.log` | 标注下载进度和错误 |

下载和最终覆盖检查运行于隐藏后台进程；不是定时任务，关机或重启后不会自动恢复。完成前不能标记完整数据已下载，也不能开始使用不完整图库报告科研指标。下载器记录的 SHA256 是本地归档指纹；完整性还由 HTTPS、长度/范围检查和 ZIP CRC 联合确认，不冒充作者发布的 SHA256。

```powershell
$py = 'C:\Users\25062\venvs\cir-clip\Scripts\python.exe'

```

最终门槛：三个 `.zip.verified.json` 均存在且 CRC 通过；两个数据集 train/val 或 val/test 标注均到位；所有公开标注引用的图片缺失数为零。正式模型评测还需 CIRCO 的完整图库清单、官方多正例 mAP 适配和训练/评测图像重叠审计，不能把本轮 sample smoke 当作整库指标。
