# 数据字典

## 1 GalleryItem

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| image_id | string | 是 | 数据集内稳定且唯一的图片标识 |
| image_path | string | 是 | 相对于数据根目录的路径 |
| split | enum | 是 | train、validation 或 test |
| category | string | 否 | 例如 FashionIQ 的 Dress、Shirt、Toptee |
| source_dataset | string | 是 | CIRR、FashionIQ 或其他已登记数据源 |
| content_sha256 | string | 是 | 文件内容校验值 |
| metadata_json | object | 否 | 不参与主键的扩展属性 |

## 2 ComposedQuery

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| query_id | string | 是 | 稳定查询标识 |
| reference_image_id | string | 是 | 参考图片 |
| modification_text | string | 是 | 修改描述，保留原始文本 |
| target_image_ids | list[string] | 是 | 一个或多个相关目标 |
| split | enum | 是 | 必须服从官方划分 |
| category | string | 否 | 数据集定义的类别 |
| source_record | string | 是 | 原始标注记录定位信息 |

## 3 QueryState

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| session_id | string | 是 | 去标识化会话标识 |
| round_id | integer | 是 | 从 0 开始单调增加 |
| reference_image_id | string | 是 | 初始参考图片 |
| initial_text | string | 是 | 初始修改文本 |
| q0_embedding_version | string | 是 | 初始向量版本 |
| current_query_vector_ref | string | 是 | 向量存储位置，不直接塞入事件日志 |
| positive_image_ids | list[string] | 是 | 明确选择或接受的图片 |
| negative_image_ids | list[string] | 是 | 明确拒绝的图片 |
| structured_feedback | object | 否 | keep、add、remove、exclude、scope 和 confidence |
| encoder_version | string | 是 | 编码器和预处理的联合版本 |
| index_version | string | 是 | 当前检索索引版本 |
| reranker_version | string | 是 | 无重排序时写 none |
| prompt_version | string | 是 | 不使用 LLM 时写 none |

## 4 FeedbackEvent

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| event_id | string | 是 | 事件唯一标识 |
| session_id | string | 是 | 关联会话 |
| round_id | integer | 是 | 关联轮次 |
| user_hash | string | 否 | 仅在伦理和隐私方案允许时保存 |
| shown_image_ids | list[string] | 是 | 实际曝光的图片 |
| shown_ranks | list[integer] | 是 | 与曝光图片一一对应 |
| shown_scores | list[float] | 是 | 与曝光图片一一对应 |
| selected_ids | list[string] | 是 | 用户选择但未必接受的图片 |
| accepted_ids | list[string] | 是 | 强正样本 |
| rejected_ids | list[string] | 是 | 强负样本 |
| free_text_feedback | string | 否 | 用户原始反馈 |
| parsed_feedback | object | 否 | 结构化解析结果 |
| latency_ms | float | 是 | 本轮端到端延迟 |
| model_versions | object | 是 | 编码器、索引、重排序和提示词版本 |
| timestamp | datetime | 是 | 带时区时间 |

未点击不等于负样本。只有显式拒绝或可靠成对比较才能作为强负样本；未点击必须保留曝光位置，并在训练中作为弱标签或不使用。

## 5 IndexManifest

| 字段 | 类型 | 说明 |
|---|---|---|
| index_version | string | 唯一、不可变版本 |
| encoder_version | string | 编码器、权重和预处理联合版本 |
| embedding_dim | integer | 向量维度 |
| metric | string | 第一版固定为归一化向量内积 |
| normalized | boolean | 必须为 true |
| item_count | integer | 索引条目数 |
| data_manifest_hash | string | 数据清单哈希 |
| build_config | object | 索引类型及参数 |
| created_at | datetime | 构建时间 |
