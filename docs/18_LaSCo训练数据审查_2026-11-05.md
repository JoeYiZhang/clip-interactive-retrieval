原始 qid 不能直接充当训练样本的唯一键。后续采用 `split + 原始行号` 标识样本，同时保留源 qid 供追溯；隔离也按原始行号进行，防止同 qid 中一条坏记录连带剔除另一条正常记录。多条文字可能描述同一图片对，不应把它们全部当作独立图片对统计。

已修复最终数据检查对 LaSCo train 的重复 qid 处理：只有显式允许该源数据特性时才保留，默认重复 ID 拒绝行为仍适用。新增测试覆盖“同 qid 一条正常、一条空文字”的逐行隔离。

有效 train/val 的图片 ID 交集和有序图片对交集均为零。与 CIRCO 已公开查询参考图及验证正例图片 ID 的交集也为零。**后者只覆盖公开查询涉及的图片，不是整个 CIRCO 图库，也不替代解码图片去重检查。**

## 接下来执行的模型工作

1. 图片下载完成并通过 ZIP CRC、解压、标注引用覆盖检查；随后构建 LaSCo 同版本冻结 CLIP 缓存。
2. 训练适配器以原始行号建立唯一查询键，按清单排除空文字并保存过滤前后统计；不修改官方文件。
3. 困难负样本只从允许的训练图片挖掘，去重候选 ID，并屏蔽同一查询已知的正确目标。训练损失需显式处理一图多描述、多正例关系。
4. 预登记固定三种子、小规模 LaSCo 训练与 FashionIQ 训练集开发区迁移对比。LaSCo val 用作预登记选模时就不再作为独立确认集；此前 FashionIQ holdout 和官方 val 不参与新一轮选参。
5. 最终候选冻结后再进行完整 CIRCO 多正例 mAP 评测。当前没有新增模型效果结论。
